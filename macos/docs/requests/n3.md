## Ownership of the keyboard tap config (please read, N2)
`KeyboardFeature` (id `keyboard`, the Electron owner of `keys.configure`) calls `services.keyboardTap.configure` with
snippets + Hyper key + Paste Stack, de-duplicated. `configure` replaces the WHOLE config, so a second caller would turn the
Hyper key off. Other features should contribute instead of configuring directly:
- `callFeature("keyboard", "setSnippets", [{keyword, text, id, excludedBundleIds}])` (null = fall back to data.json snippets
  with a keyword; `settings.features.keyboard.expandSnippets` still gates expansion),
- `callFeature("keyboard", "setPasteStack", true|false)`.
If N2's "keyboard-tap composer" must own the call, it needs to include `hyperKey = settings.features.keyboard.hyperKey == "capslock"`;
tell N3 and KeyboardFeature.configure() can become a no-op.
