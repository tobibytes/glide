# N1 (Files, Conversions, Calculator, Fallbacks, Quicklinks 2.0, Emoji): notes on shared files

## Small additive edits already made (please keep)
1. `Sources/GlideApp/Launcher/MultiArgument.swift` (new file): multi-argument entry for items with
   `item.data["arguments"] = [{name, placeholder, default?, options?, optional}]`. In argument mode,
   Tab / ⇧Tab move between the pills, ↑/↓ cycle a field's options, and Backspace on an empty field goes back.
   The action receives `ScoredItem.arguments`.
2. `LauncherState.swift`: `ArgumentMode.multi: MultiArgumentState?`.
3. `LauncherController.swift`:
   - `active` fills `arguments`.
   - `placeholder` shows the current pill.
   - `rootKey` sends keys to `MultiArgument.key` first.
   - The new `beginArgument(_:)` handles Tab.
   - `.activate` opens the pills when a required argument is empty.
   - In `runSearch`, a selection still on the first row now follows the new first row when dynamic rows
     arrive. Calculator and conversion rows land above the fallbacks, which used to keep the selection.
4. `LauncherView.swift`: `ArgumentPills` is shown next to the argument chip (1 line).
5. `TestServer.swift`: `state()` reports `"arguments"` (the pills) in argument mode (1 line).
6. `AllFeatures.swift`: the built-in `QuicklinksFeature()` line is replaced by `Quicklinks2Feature()`
   (same id "quicklinks", same item ids). Convert, Emoji, Fallbacks and Files are added.
7. `Package.swift`: test target `N1FeatureTests` (Tests/N1FeatureTests).

  lines to stdout instead, so these do not appear in the `headless.effects` list.
