# N7 (Notes, Timers, Focus, Calendar, Reminders, Color, OCR, Browser) — shared-file notes

## Small additive edits already made (please keep)
1. `Sources/GlideUI/FeatureUI.swift`
   - `FeatureCommandHandling` protocol: `handleCommand(_ VimCommand, view:) -> Bool`. Pushed views with their
     own list get the launcher's vim commands (move/goto/halfPage/section/activate/secondary/actions/delete/
     copy/paste) first, so j/k, gg/G, counts, ⌃D/⌃U, ⏎, ⌘⏎, ⌘K, x/y/p work inside feature views with the
     shared Vim state (the launcher still owns NORMAL/INSERT).
   - `LauncherHosts.current`: the launcher's `LauncherViewHost`, available before a pushed view renders
     (headless runs never render a view until a snapshot, so `launcherView(..., host:)` may not have been
     called yet when keys arrive).
2. `Sources/GlideApp/Launcher/LauncherController.swift` `apply(_:)`: offers the command to
   `FeatureCommandHandling` of the top view first (3 lines).
3. `Sources/GlideApp/Launcher/LauncherPanel.swift`: `LauncherHosts.current = host` (1 line).
4. `Package.swift`: test target `N7FeatureTests` (Tests/N7FeatureTests), depends on GlideFeatures.

## Methods other sessions call (kept stable)
- `timers.start {ms, name}` (N6 workflow action, N5 agent) — returns `{ok, message|error}`. Also
  `timers.state` (Electron TimersState shape: timers/stopwatches/presets/now/settings/sounds), `toggle`,
  `add {id, ms}`, `stop`, `restart`, `startPreset`, `stopwatchToggle`, `stopwatchRemove`, `lap`… — each
  takes `{id}` or a bare string id (N8 menu bar passes `.string(id)`).
- `ocr.captureText {}` → `{text, result}` or `{text: "", cancelled: true}` (N6). Never runs
  `screencapture` in headless runs (recorded in `ocr.effects`).
- `calendar.schedule` (`{status, message, from, to, events[] with meeting}`), `calendar.join` (url string),
  `calendar.openCalendar` (ISO string or unix-ms number), `calendar.requestAccess` (explicit user action only).
- `notes.create {body|text}`, `save {id, body}`, `remove {id}`, `search {query}`, `open {id}`.
- `reminders.create {title, due?, allDay?, listId?, notes?}`, `complete {id, completed}` (no `delete`:
  EventKitService has no delete; callers fall back to complete).
- `browser.search {query, type|kind, limit}`.

## Headless seams (tests/driver only)
- `GLIDE_EVENTKIT_FIXTURE=<json>` → `FixtureEventKit` (GlideSystem/Native/EventKit.swift, additive) for
  Calendar + Reminders in headless runs.
- `GLIDE_BROWSER_HOME=<dir>`: the only way a headless run reads browser data (fixture home).
- `GLIDE_HEADLESS_CLIPBOARD_IMAGE=<png>` / `ocr.setHeadlessClipboardImage` for "from clipboard image".
