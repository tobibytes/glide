## Methods the agent / MCP server call on other features (`callFeature(id, method, args)`, args are JSON objects)
Tools needing a feature are hidden when the feature isn't installed (probed with an unknown method → `unknownMethod`
means installed). Please accept these shapes (they mirror the Electron positional arguments):
- timers: `state` → `{timers:[{id,name,durationMs,startedAt,pausedAt,pausedMs|remainingMs}], stopwatches:[…]}`,
  `start {ms, name}`, `stop {id}`
- notes: `create {text}` → `{id, body?}` (if body differs, `save {id, text}` is called), `search {query}` → `[{id,title,preview}]`,
  `open {id}`, `remove {id}` → bool, `get {id}` → `{id, body}`
- automations: `state` → `{automations:[{id,name,enabled,triggerText,targetText}]}`, `save {name,trigger,target,askBeforeRunning,enabled}`
  → `{ok, automation:{id}}`, `remove {id}`, `runNow {id}`
- layouts: `state` → `{layouts:[{id,name,summary|windows}]}`, `restore {id}`, `save {name}` → `{id, windows}`, `deleteLayout {id}`
- transforms: `list` → `[{id,title,category}]`, `apply {id, input}` → `{ok, output}`
- browser: `search {query, kind:"bookmark", limit}`; clipboard: `list {query, limit}`; processes: `list`, `risk {pid}`,
  `signal {pid, signal, confirmed, expectedCommand}`; sysmon: `sample`; reminders: `state`, `create {title, due?, notes?}`,
  `delete {id}` / `complete {id, completed}`; convert: `preview {query}`; workflows: `run {id, input}` (falls back to
  executing `workflow:<id>`).

## Wished for

- Launcher ⌘⏎ from the root search → `callFeature("agent", "openFromLauncher", {query})` (the Electron launcher
  shortcut; needs a LauncherController hook).
- A way to ask whether a pushed view is still on the stack (the agent re-pushes `agent.run` after a tool hid the
  launcher; today it can't tell and may stack a duplicate).
