Everything in one place

One shortcut. Your whole Mac.

Glide replaces a handful of utilities with one fast, native app.

Search everything

Apps, files, commands, bookmarks and more, ranked by what you use most. Fuzzy matching, aliases and per-command hotkeys.

Clipboard & snippets

Searchable clipboard history (including the text inside copied images), a paste stack, and snippets that expand as you type in any app.

Windows & workspaces

Halves, thirds and quarters across displays. Save layouts, and open a whole workspace of apps, links and a focus session at once.

AI, your way

Quick AI, AI Chat and one-key commands like fix spelling or summarize. Use your own Anthropic or OpenAI key, or a local model through Ollama or LM Studio.

Glide Agent

Describe a task in plain words. The agent shows its plan, asks before changing anything, and can undo or save the task as a workflow.

Automations

Run workflows on a schedule, when an app opens, when Wi‑Fi or power changes, or when a new file lands in a folder. Build them visually, no code needed.

Screen text & QR

Drag over anything on screen to copy its text, or scan a QR code. Recognition runs on your Mac.

Extensions & MCP

Install from the extension store or run Raycast-style React extensions. Glide is also an MCP server, so tools like Claude Code can use it.

Mac utilities built in

Color picker, process and port killer, system monitor, menu search, timers, focus sessions, floating notes, reminders and calendar.

Easy to learn

Not sure what it can do? Ask it.

Type help and open What Can Glide Do? to see every command grouped by feature, with examples you can try in one keystroke.

  • Keyboard-first: ⌘K shows the actions for anything, with optional vim keys.
  • Make it yours: 9 themes, light and dark, density and size.
  • Sync without an account: point Glide at iCloud Drive or Dropbox. Secrets never sync.

Install

Up and running in a minute.

  1. Download the latest Glide .dmg, open it, and drag Glide onto Applications.
  2. Glide isn't notarized by Apple yet, so the first launch is blocked. Open System Settings → Privacy & Security and click Open Anyway next to the message about Glide.
  3. Press ⌘ Space. Glide walks you through your hotkey, permissions, an optional AI key and a theme. After that, it updates itself.
